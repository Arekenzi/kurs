# Как превратить это в приложение с постоянными данными

Внутри архива пять файлов. Их нужно положить на любой бесплатный
статический хостинг. Требование одно: **адрес не должен меняться при
обновлениях** — тогда данные переживают любые новые версии.

---

## Вариант 1. Netlify Drop — самый быстрый, без регистрации

1. Открой `app.netlify.com/drop`
2. Перетащи туда **папку целиком** (не отдельные файлы)
3. Через несколько секунд получишь адрес вида `random-name.netlify.app`
4. Открой его на телефоне → «Поделиться» → **«На экран Домой»**

Чтобы адрес закрепился за тобой и не потерялся, там же можно бесплатно
завести аккаунт и переименовать сайт.

Обновление: заходишь в проект → Deploys → перетаскиваешь новую папку.
Адрес прежний, данные на месте.

---

## Вариант 2. GitHub Pages — навсегда и бесплатно

1. Создай репозиторий на github.com, назови например `kurs`
2. Загрузи туда все файлы из папки (Add file → Upload files)
3. Settings → Pages → Source: `main`, папка `/ (root)` → Save
4. Через минуту сайт будет по адресу `ИМЯ.github.io/kurs/`
5. Открой на телефоне → «Поделиться» → «На экран Домой»

Обновление: загружаешь новый `index.html` поверх старого.

---

## Вариант 3. Свой домен

Если есть свой хостинг — просто скопируй файлы в любую папку и открой её
адрес. Обязательно **https**, иначе офлайн-режим и установка не включатся.

---

## Что даёт установка на экран «Домой»

- Иконка, запуск без адресной строки, вид обычного приложения
- Работа без интернета — файлы кэшируются
- **Данные не пропадают при обновлениях**, потому что адрес один и тот же

## Чего установка не даёт

Напоминаний при закрытом приложении. Их по-прежнему даёт только выгрузка
в календарь: «Ещё» → «Выгрузить в календарь телефона».

---

## Перенос текущих данных

1. В старой версии: «Ещё» → «Скачать копию файлом»
2. Открой новый адрес, установи на экран «Домой»
3. «Ещё» → «Загрузить копию из файла» → выбери скачанный файл

Дальше копию делай раз в пару недель — на случай, если сотрёшь сайт из
истории или переустановишь телефон.

## При обновлении версии

Если после заливки новой версии приложение открылось старым — закрой его,
открой заново. Если не помогло: в файле `sw.js` поменяй строку
`var CACHE = "kurs-v1";` на `"kurs-v2"` и залей ещё раз.

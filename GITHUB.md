# Заливка на GitHub Pages — подробно

Результат: постоянный адрес вида `https://твойлогин.github.io/kurs/`,
иконка на экране «Домой», работа без интернета и данные, которые не
пропадают при обновлениях.

Всё бесплатно. Удобнее делать с компьютера, но можно и с телефона.

---

## Шаг 0. Распакуй архив

`kurs-pwa.zip` нужно распаковать. Загружать на GitHub надо **6 файлов
по отдельности**, сам архив он не распакует.

Внутри должны быть:

    index.html
    manifest.webmanifest
    sw.js
    icon-192.png
    icon-512.png
    icon-maskable.png

На iPhone: «Файлы» → долгое нажатие на архив → «Распаковать».

---

## Шаг 1. Аккаунт

1. `github.com` → **Sign up**
2. Почта, пароль, логин. Логин попадёт в адрес сайта — выбирай короткий
   и латиницей, например `artur-kz`.
3. Подтверди почту.

---

## Шаг 2. Репозиторий

Репозиторий — это папка с файлами на GitHub.

1. Справа вверху **+** → **New repository**
2. **Repository name**: `kurs` (латиницей, без пробелов)
3. **Public** — обязательно. На бесплатном тарифе Pages работает только
   с публичными репозиториями.
4. Галочку *Add a README file* можно поставить, можно нет
5. **Create repository**

> Public означает, что код приложения виден всем, кто знает адрес.
> Твои данные — схема, дозы, анализы — в репозиторий не попадают: они
> хранятся только в браузере телефона. Но само приложение и справочник
> будут публично доступны. Если это не устраивает — бери Netlify, там
> исходники не публикуются.

---

## Шаг 3. Загрузка файлов

1. На странице репозитория: **Add file** → **Upload files**
2. Перетащи все 6 файлов (или **choose your files**)
3. Дождись, пока все шесть появятся в списке
4. Внизу **Commit changes**

Важно: файлы должны лежать в корне, не внутри вложенной папки.
После загрузки на главной странице репозитория должен быть виден
`index.html` — если он внутри папки `pwa`, зайди в неё, удали, и
загрузи файлы заново по одному.

---

## Шаг 4. Включить Pages

1. Вкладка **Settings** сверху
2. Слева в разделе «Code and automation» — **Pages**
3. **Source**: `Deploy from a branch`
4. **Branch**: `main`, папка `/ (root)`
5. **Save**

Подожди 1–2 минуты и обнови страницу. Наверху появится адрес:

    https://твойлогин.github.io/kurs/

---

## Шаг 5. На телефон

1. Открой адрес в **Safari** (именно в Safari, не в Chrome)
2. Кнопка «Поделиться» внизу
3. **«На экран Домой»**
4. Назови «Курс» → «Добавить»

Появится иконка. Запускается без адресной строки, как приложение.

---

## Шаг 6. Перенести данные

1. В старой версии: «Ещё» → **«Скачать копию файлом»**
2. Открой приложение с иконки
3. «Ещё» → **«Загрузить копию из файла»** → выбери скачанный файл

Проверь, что появились препараты и дата старта.

---

## Обновление на новую версию

1. Репозиторий → клик по `index.html` → карандаш (Edit)
   ИЛИ **Add file → Upload files** и загрузи новый `index.html` поверх
2. **Commit changes**
3. Через минуту закрой приложение на телефоне и открой заново

Адрес прежний → хранилище прежнее → **данные на месте**.

Если открылась старая версия: в файле `sw.js` поменяй
`var CACHE = "kurs-v1";` на `"kurs-v2"` и закоммить. Это сбрасывает кэш.

---

## Если что-то не работает

**«Deploy from a branch» неактивен** — репозиторий приватный. Settings →
General → Danger Zone → Change visibility → Public.

**Страница 404** — не прошло двух минут, либо `index.html` лежит внутри
папки, а не в корне.

**Иконка не появилась** — открывал не в Safari.

**Нет пункта «На экран Домой»** — открой сайт не в приватной вкладке.

---

## Про напоминания

Установка на экран «Домой» даёт иконку, офлайн и постоянные данные, но
**не даёт напоминаний при закрытом приложении** — это ограничение любого
сайта. Напоминания по-прежнему через «Ещё» → «Выгрузить в календарь».
